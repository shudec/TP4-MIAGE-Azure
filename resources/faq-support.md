# Base de connaissances du support informatique

Version : 1.0

## Réinitialisation du mot de passe

Utiliser le portail libre-service `https://passwordreset.microsoftonline.com`. Après cinq tentatives infructueuses, attendre quinze minutes avant de recommencer. Le support ne demande jamais le mot de passe d'un utilisateur.

## Authentification multifacteur

En cas de changement de téléphone, ouvrir un ticket de catégorie **Compte et accès / MFA**. Joindre son identifiant étudiant, mais aucune copie de mot de passe ni aucun code temporaire.

## Connexion au VPN

Le VPN est nécessaire uniquement pour accéder aux ressources internes depuis l'extérieur. Vérifier la connexion Internet, redémarrer le client VPN puis choisir la passerelle **France**. Si le code `VPN-403` apparaît, renouveler l'authentification multifacteur.

## Wi-Fi du campus

Le réseau à utiliser est **EDU-CAMPUS**. S'authentifier avec l'adresse universitaire complète. Oublier puis ajouter de nouveau le réseau si un ancien mot de passe reste mémorisé.

## Messagerie

La taille maximale d'une pièce jointe est de 20 Mo. Au-delà, déposer le document sur OneDrive et envoyer un lien avec les permissions appropriées.

## Installation de logiciels

Les logiciels du catalogue interne peuvent être installés sans droits administrateur depuis le **Portail d'entreprise**. Toute autre installation nécessite un ticket de catégorie **Poste de travail / Logiciel**.

## Ordinateur bloqué

Maintenir le bouton d'alimentation pendant dix secondes uniquement si le système ne répond plus depuis au moins cinq minutes. Après redémarrage, noter l'heure et l'application utilisée si le blocage se reproduit.

## Équipement endommagé

Éteindre et débrancher immédiatement tout équipement ayant reçu un liquide. Ne pas tenter de le rallumer. Contacter le support par téléphone et indiquer le numéro d'inventaire.

## Impression

Le quota étudiant est de 200 pages par semestre. Une impression bloquée peut être annulée depuis `https://print.miage.example`. Le rechargement du quota relève du secrétariat pédagogique.

## Sauvegarde des fichiers

Les documents pédagogiques doivent être enregistrés dans OneDrive. Les fichiers conservés uniquement dans le dossier Téléchargements ne sont pas sauvegardés par le service informatique.

## Horaires et contact

Le support est ouvert du lundi au vendredi, de 8 h 30 à 17 h 30. Les incidents bloquants sont joignables au 01 00 00 00 42. Les autres demandes passent par `https://support.miage.example`.

## Escalade

Créer un ticket si la procédure documentée échoue deux fois, si un message d'erreur n'est pas référencé, ou si la demande concerne des données sensibles. Le ticket doit contenir le service touché, l'heure, le message d'erreur et les actions déjà tentées.
